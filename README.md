# NIGHTWATCH

A night-shift operator console for the EOG Resources Beat the Shutdown challenge at HackUTD 2026.

## Development

Use Node.js 24 and Git. In PowerShell use `npm.cmd` if script execution is restricted.

```sh
npm ci
npm run data
npm run dev
```

Practice data comes from the [official EOG repository](https://github.com/nihaal419/HackUTD-ZeroDay). The application uses only the network, operations, and telemetry files. The upstream answer keys stay outside the browser's public directory.

NIGHTWATCH uses React, Vite, TypeScript, and React Three Fiber. Codex generated and tested code for this project. Confirm the current HackUTD AI-assistance rules and disclose that assistance before submission.
